# 工作流创建教程

## 📊 什么是工作流？

工作流是 **LocalMind 的核心功能**，让 AI 从"聊天"变成"行动"。

### 简单理解
```
普通聊天：
  你："帮我总结这封邮件"
  AI："好的，总结是..."

工作流：
  你："每周一早上 9 点总结上周邮件并创建本周任务"
  AI："✅ 已创建工作流 'Weekly Email Summary'，
       将在每周一 9:00 自动执行"
```

### 工作流的优势
- ⏰ **自动化**：一次设置，永久运行
- 🔄 **多步骤**：串联多个操作
- 🧠 **智能**：AI 自动规划执行步骤
- 📊 **可视化**：清晰看到执行流程

---

## 🎯 创建第一个工作流

### 方法 1：自然语言创建（推荐）

#### 步骤 1：打开工作流界面
1. 主界面点击左上角 **☰ 菜单**
2. 选择 **📊 工作流**
3. 点击右上角 **+** 号

#### 步骤 2：描述你的需求
在输入框中用自然语言描述任务：

```
示例 1：简单任务
"每天早上 8 点告诉我今天的日程安排"

示例 2：复杂任务
"每周五下午 5 点总结本周完成的任务，
 并生成下周计划，发送到我的邮箱"

示例 3：带条件
"如果明天有会议，提前 1 小时提醒我；
 如果没有，就不提醒"
```

#### 步骤 3：AI 自动生成工作流
LocalMind 会：
1. 解析你的需求
2. 生成执行步骤
3. 显示可视化流程图

```
生成的流程图示例：

[定时器: 每天 8:00]
        ↓
[调用 ios.calendar.query]
  查询今天日程
        ↓
[本地 LLM: 格式化]
  整理成易读格式
        ↓
[发送通知]
  显示今日日程
```

#### 步骤 4：确认或修改
- ✅ 满意：点击 **保存**
- ⚠️ 需修改：点击 **编辑步骤**（进入可视化编辑器）

## 🎨 可视化编辑器详解

### 编辑器界面

```
┌───────────────────────────────────────┐
│  工作流：每日日程提醒     [保存] [×]  │
├───────────────────────────────────────┤
│                                   │
│  [定时器]     [查询日历]     [LLM] │
│   每天8:00  → 今日日程  →  格式化  │
│      ↓            ↓            ↓      │
│  [发送通知]    [条件判断]    [结束] │
│   显示结果    → 如果失败?          │
│                                   │
│  ➕ 添加步骤                         │
│                                   │
│  📋 工作流 JSON                    │
│  {                                 │
│    "trigger": "schedule",           │
│    "time": "0 8 * * *",           │
│    ...                             │
│  }                                 │
└───────────────────────────────────────┘
```

### 可用步骤类型

#### 1️⃣ 触发器（Trigger）
决定工作流何时启动：

| 类型 | 说明 | 示例 |
|------|------|------|
| **定时触发** | 按 cron 表达式 | 每天 9 点、每周一 |
| **事件触发** | 系统事件 | 到达某地、收到邮件 |
| **手动触发** | 用户主动启动 | 点击运行按钮 |

**设置定时触发**：
```
Cron 表达式：0 9 * * 1-5
含义：周一到周五，每天 9:00

简单模式：
- 每天 [时间]
- 每周 [星期] [时间]
- 每月 [日期] [时间]
```

#### 2️⃣ 动作步骤（Action）
执行具体操作：

**iOS 系统工具**：
- 📅 **日历查询**：获取日程、创建事件
- ⏰ **提醒设置**：创建提醒、标记完成
- 🏠 **HomeKit**：控制灯光、开关、场景
- 💊 **健康查询**：步数、心率、睡眠
- 📁 **文件操作**：读取、写入、搜索
- 📷 **照片搜索**：按日期、地点、内容

**AI 处理**：
- 🤖 **LLM 总结**：文本摘要、关键信息提取
- 🌐 **LLM 翻译**：多语言互译
- 📝 **LLM 生成**：写邮件、写报告、写代码

**输出动作**：
- 📲 **发送通知**：本地推送通知
- 📧 **发送邮件**：到指定邮箱
- 💬 **发送消息**：iMessage/WhatsApp
- 📄 **导出文件**：保存为 Markdown/PDF

#### 3️⃣ 逻辑控制（Logic）
让工作流更智能：

**条件判断**：
```
[查询天气]
     ↓
[条件：是否下雨？]
   ↙    ↘
是      否
↓       ↓
[带伞提醒] [无需提醒]
```

**循环**：
```
[循环：对于邮件列表中的每封邮件]
     ↓
[LLM 总结邮件]
     ↓
[标记为已处理]
```

**错误处理**：
```
[执行任务]
     ↓
[是否出错？]
   ↙    ↘
是      否
↓       ↓
[重试3次] [继续]
```

## 📝 实战示例

### 示例 1：邮件智能助手

**需求描述**：
```
"每周一早上 9 点总结上周收件箱的邮件，
 将重要邮件转发给老板（boss@company.com），
 广告邮件自动归档，并生成待回复邮件列表"
```

**生成的工作流**：
```
[定时器: 每周一 9:00]
        ↓
[调用 ios.mail.query]
  获取上周收件箱邮件
        ↓
[LLM: 分类邮件]
  分为：重要 / 广告 / 待回复
        ↓
    ┌───┴───┐
    ↓       ↓       ↓
[转发老板] [归档] [生成列表]
    ↓       ↓       ↓
    └───┬───┘
        ↓
[发送通知]
   "邮件处理完成，共处理 23 封"
```

**测试运行**：
1. 点击 **▶️ 测试运行**
2. 观察每步执行结果
3. 查看最终输出

### 示例 2：健康生活教练

**需求描述**：
```
"每天晚上 10 点分析今天的运动和睡眠数据，
 如果步数少于 8000 步，提醒我明天多运动；
 如果睡眠少于 7 小时，建议调整作息"
```

**生成的工作流**：
```
[定时器: 每天 22:00]
        ↓
[HealthKit: 查询今日数据]
  步数、心率、睡眠时长
        ↓
[LLM: 分析数据]
  生成健康建议
        ↓
[条件：步数 < 8000？]
   ↙        ↘
  是         否
  ↓          ↓
[提醒明天多运动] [继续]
              ↓
[条件：睡眠 < 7h？]
   ↙        ↘
  是         否
  ↓          ↓
[建议调整作息] [无需提醒]
              ↓
[发送通知]
  显示今日健康总结
```

### 示例 3：智能家居场景

**需求描述**：
```
"当我下班回家且天黑时（通过位置和时间判断），
 自动打开客厅灯、空调调到 24°C、
 并播放我喜欢的音乐"
```

## 🔄 工作流管理

### 查看所有工作流
工作流列表显示：
- **名称**：工作流名称
- **状态**：运行中 / 已暂停 / 出错
- **上次运行**：最后执行时间
- **下次运行**：下次执行时间

### 工作流操作
**长按工作流**，弹出菜单：
```
┌──────────────────┐
│  ▶️ 立即运行       │
│  ⏸️ 暂停/恢复     │
│  ✏️ 编辑          │
│  📋 复制          │
│  📤 导出          │
│  🗑️ 删除          │
│  📊 查看运行历史   │
└──────────────────┘
```

### 运行历史
点击工作流 → **运行历史**，查看：
- 每次运行的时间
- 是否成功
- 执行时长
- 详细日志（每步的输入输出）

## 📤 导入/导出

### 导出工作流
1. 长按工作流
2. 选择 **导出**
3. 选择格式：
   - **JSON**：完整配置，可编辑
   - **YAML**：人类可读，简洁
   - **分享链接**：生成可分享的链接

### 导入工作流
1. 工作流列表 → 右上角 **+**
2. 选择 **导入**
3. 从 Files 选择文件，或粘贴分享链接

## 💡 最佳实践

### 设计原则
1. **单一职责**：每个工作流只做一件事
2. **错误处理**：关键步骤加错误重试
3. **日志记录**：重要数据保存到文件
4. **适度通知**：别让用户被通知轰炸

### 性能优化
- ⚠️ 避免过于频繁触发（如每分钟）
- ✅ 使用原生工具而非 LLM（更快更省电）
- ✅ 限制循环次数（防止死循环）
- ✅ 清理不再需要的工作流

### 调试技巧
**工作流不运行？**
1. 检查是否开启 **后台执行权限**
2. 查看 **运行历史** 的错误日志
3. 测试运行观察在哪步失败

**AI 处理不准确？**
1. 优化提示词（更明确的要求）
2. 调整 Temperature（降低到 0.3）
3. 拆分复杂任务为多个简单工作流
