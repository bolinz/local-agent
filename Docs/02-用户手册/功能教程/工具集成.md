# 工具集成教程

## 🔧 什么是工具？

工具是 **LocalMind 执行的"双手"**，让 AI 能真正操作你的设备。

### 工具分类

```
LocalMind 工具生态
        │
    ┌───┴───┐
    ↓       ↓
 内置工具   扩展工具
    │       │
┌───┴───┐ ┌───┴───┐
│ iOS   │ │ HTTP  │

│ 框架  │ │ 服务器│
└───┬───┘ └───┬───┘
    ↓           ↓
 15+工具   用户自定义
```

## 📱 内置 iOS 工具（15+）

### 1️⃣ 健康工具（HealthKit）

**可用功能**：
- **查询健康数据**：步数、心率、睡眠、体重、血氧等
- **分析趋势**：对比历史数据
- **生成建议**：AI 给健康建议

**使用示例**：
```
你："分析我上周的睡眠数据，给出改善建议"

LocalMind：[调用 ios.health.query]
  - 上周平均睡眠：6.2 小时
  - 深睡眠占比：18%（偏低）
  - 入睡时间：平均 23:45

[调用 ios.llm.analyze]
  建议：
  1. 提前 30 分钟上床（23:15）
  2. 睡前 1 小时避免屏幕
  3. 保持卧室温度 18-22°C
```

**授权设置**：
设置 → 隐私 → 健康 → 开启 LocalMind 权限

---

### 2️⃣ 日历与提醒（EventKit）

**可用功能**：
- **查询日程**：今天/本周/本月的事件
- **创建事件**：添加日历项，设置提醒
- **管理提醒**：创建、标记完成、删除

**使用示例**：
```
你："明天下午 3 点有个项目会议，提前半小时提醒我"

LocalMind：[调用 ios.calendar.create]
  ✅ 已创建事件：
  - 标题：项目会议
  - 时间：明天 15:00-16:00
  - 提醒：14:30（提前 30 分钟）
```

**批量操作示例**：
```
你："把这段对话转成 3 个提醒事项：
  1. 买菜
  2. 预约牙医
  3. 回复客户邮件"

LocalMind：[调用 ios.reminders.create] × 3
  ✅ 已创建 3 个提醒事项
```

### 3️⃣ 智能家居（HomeKit）

**可用功能**：
- **控制设备**：灯光、开关、空调、窗帘等
- **场景联动**：一键执行多个操作
- **状态查询**：查看设备当前状态

**使用示例**：
```
你："晚安模式：关闭所有灯光，锁门，设置明天 7 点闹钟"

LocalMind：[调用 ios.homekit.execute]
  ✅ 晚安模式已执行：
  - 客厅灯：已关闭 ✓
  - 卧室灯：已关闭 ✓
  - 前门：已锁定 ✓
  - 闹钟：已设置为 07:00 ✓
```

**条件控制示例**：
```
你："如果客厅温度高于 28°C，自动开空调 26°C"

LocalMind：创建持久化监听工作流
  [定时: 每小时]
     ↓
  [查询温度] → [条件: > 28°C?]
              ↙        ↘
             是         否
             ↓          ↓
        [开空调26°C]   [结束]
```

**授权设置**：
设置 → 隐私 → HomeKit → 开启 LocalMind 权限

## 🌐 扩展工具

### 1️⃣ HTTP 请求工具

**功能**：调用任意网络 API

**使用示例**：
```
你："查询比特币当前价格"

LocalMind：[调用 network.http.get]
  URL: https://api.coinbase.com/v2/prices/BTC-USD/spot
  
[解析 JSON 响应]
  💰 比特币当前价格：$65,432.10
```

**POST 请求示例**：
```
你："用我的 OpenAI API 总结这篇文章"

LocalMind：[调用 network.http.post]
  URL: https://api.openai.com/v1/chat/completions
  Headers: Bearer [你的 API Key]
  Body: { "model": "gpt-4", "messages": [...] }
  
[返回总结结果]
```

**配置 API Key**：
设置 → 高级选项 → API 密钥管理 → 添加 OpenAI Key

### 2️⃣ MCP 服务器连接（Pro+ 版）

**什么是 MCP？**
Model Context Protocol（模型上下文协议），让 AI 连接外部服务。

**支持的操作**：
- 连接你自己的 HTTP MCP 服务器
- 使用服务器提供的工具（如 Home Assistant、Notion、GitHub）
- 扩展 LocalMind 能力

**设置步骤**：
1. 设置 → 高级选项 → MCP 服务器
2. 点击 **+** 添加服务器
3. 输入服务器 URL（如 `http://192.168.1.100:8080`）
4. 点击 **测试连接**
5. 成功后，服务器工具会自动出现在工具列表中

**使用示例**：
```
你："查询我家里的温度（通过 Home Assistant）"

LocalMind：[调用 mcp.homeassistant.get]
  客厅温度：24.5°C
  卧室温度：23.8°C
```

## 🛠️ 自定义工具（开发版）

### 创建自定义工具
**注意**：此功能需要技术背景

**工具定义格式**（JSON）：
```json
{
  "name": "my_tool.calculate",
  "description": "计算数学表达式",
  "parameters": {
    "type": "object",
    "properties": {
      "expression": {
        "type": "string",
        "description": "数学表达式，如 2+3*4"
      }
    },
    "required": ["expression"]
  }
}
```

**工具实现**（Swift 代码示例）：
```swift
struct CalculateTool: AgentTool {
    let name = "my_tool.calculate"
    let description = "计算数学表达式"
    
    func execute(parameters: [String: String]) async throws -> String {
        let expr = parameters["expression"]!
        // 调用计算引擎
        let result = evaluate(expr)
        return "计算结果：\(result)"
    }
}
```

```
你："帮我做这些事：
  1. 查询今天日程
  2. 如果下雨提醒我带伞
  3. 把重要邮件转发给老板"

  → ios.calendar.query
  → network.weather.get
```

```
你："用健康工具查询我上周的步数"

LocalMind 会优先使用：
  → ios.health.query (data_type: "steps", days: 7)
```

在设置中开启 **显示工具调用日志**：

```
[你] 我的心率是多少？
[调用工具] ios.health.query
  参数: {"data_type": "heart_rate", "days": 1}
[返回结果] 72 bpm
[LLM] 你的当前心率是 72 次/分钟...
```

## ⚠️ 常见问题

### Q：工具调用失败怎么办？
**A**：检查：
1. 是否授权了对应权限
2. 设备是否支持该功能（如 HealthKit 需要 iPhone 6s+）
3. 查看工具调用日志（设置 → 高级选项 → 日志）

### Q：如何知道有哪些工具可用？
**A**：
1. 设置 → 工具管理 → 查看所有工具
2. 或在聊天中问："你有哪些工具可以用？"

### Q：可以禁用某些工具吗？
**A**：可以。
设置 → 工具管理 → 点击工具 → 关闭开关
