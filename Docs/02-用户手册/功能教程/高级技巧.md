## 🎯 提示词（Prompt）优化

### 什么是好的提示词？

**对比示例**：

❌ **不好的提示词**：
```
"帮我写点东西"
"分析这个"
"处理数据"
```

✅ **好的提示词**：
```
"用 300 字写一篇关于人工智能发展前景的文章，
 包含 3 个关键点，适合普通读者阅读"

"分析以下销售数据（CSV 格式），找出：
 1. 销售额最高的月份
 2. 同比增长率
 3. 给出改进建议"

"将这些会议记录整理成：
 - 关键决策（用加粗）
 - 待办事项（用复选框）
 - 负责人分配"
```

### 提示词结构模板

```
[角色定义] + [任务描述] + [输出要求] + [约束条件]

示例：
[角色] 你是一位资深 Swift 开发者
[任务] 审查以下代码并找出潜在问题
[输出] 用 Markdown 列表，每条包含：
      - 问题位置（行号）
      - 问题描述
      - 修复建议
[约束] 只关注严重问题，忽略风格问题
```

### 常用提示词技巧

#### 1️⃣ 少样本学习（Few-Shot）
```
"请按照以下示例的格式总结文章：

示例输入：iPhone 15 Pro 评测...
示例输出：
- 核心亮点：A17 Pro 芯片性能提升 20%
- 主要缺点：重量增加 10%
- 适合人群：专业用户、内容创作者

现在总结这篇关于 MacBook Pro M3 的文章：[文章内容]"
```

#### 2️⃣ 思维链（Chain of Thought）
```
"请一步步分析这个数学问题：

问题：一个水池有 2 个进水管，单独开分别需要 4 小时和 6 小时注满...

步骤 1：理解问题，列出已知条件
步骤 2：计算每个水管的注水速度
步骤 3：计算同时开的注水速度
步骤 4：计算总时间
步骤 5：验证结果是否合理

现在开始："
```

#### 3️⃣ 角色扮演
```
"你现在是我的私人健身教练，拥有 10 年经验。
 请根据我的健康数据（见下）给出专业建议。
 
 我的数据：
 - 步数：日均 5000 步
 - 体重：75kg
 - 目标：3 个月减到 70kg
 
 请给出：每周训练计划、饮食建议、进度追踪方法"
```

## ⚙️ 模型参数调优

### 核心参数说明

#### Temperature（温度）
**控制生成的随机性**

| 值 | 效果 | 适用场景 |
|-----|------|----------|
| 0.1-0.3 | 确定性强，输出稳定 | 翻译、代码、数据提取 |
| 0.5-0.7 | 平衡（推荐） | 日常对话、总结、问答 |
| 0.8-1.2 | 创意性强，有惊喜 | 写作、头脑风暴、起名字 |
| 1.5+ | 非常随机，可能胡说 | 创意探索（慎用） |

**调整方法**：
设置 → 模型设置 → Temperature → 拖动滑块

#### Top-P（核采样）
**控制候选词的范围**

| 值 | 效果 | 说明 |
|-----|------|------|
| 0.1-0.5 | 聚焦高概率词 | 更准确，但可能重复 |
| 0.9（默认） | 平衡 | 推荐日常使用 |
| 0.95-1.0 | 包含更多低概率词 | 更多样化，但可能不连贯 |

#### Top-K
**限制每步最多考虑 K 个词**

| 值 | 效果 |
|-----|------|
| 10-20 | 非常聚焦，保守 |
| 40-50（默认） | 平衡 |
| 100+ | 更开放，更多样 |

#### Repetition Penalty（重复惩罚）
**降低重复生成的概率**

| 值 | 效果 |
|-----|------|
| 1.0（默认） | 无惩罚 |
| 1.1-1.3 | 轻度惩罚，推荐 |
| 1.5+ | 强惩罚，可能生成不自然 |

---

### 场景化参数推荐

#### 📝 写作任务
```
Temperature: 0.8
Top-P: 0.92
Top-K: 50
Repetition Penalty: 1.2
```

#### 💻 代码生成
```
Temperature: 0.2
Top-P: 0.95
Top-K: 40
Repetition Penalty: 1.1
```

#### 📊 数据总结
```
Temperature: 0.3
Top-P: 0.90
Top-K: 30
Repetition Penalty: 1.1
```

#### 🈶 翻译
```
Temperature: 0.1
Top-P: 0.95
Top-K: 20
Repetition Penalty: 1.0
```

**快速切换**：
设置 → 参数预设 → 选择场景（写作/代码/总结/翻译）

## 📊 工作流设计模式

### 模式 1：管道模式（Pipeline）
```
任务：处理邮件并生成报告

[获取邮件] → [过滤重要邮件] → [LLM 总结] → [生成报告] → [发送]
```

**适用**：线性任务，步骤清晰

---

### 模式 2：分支模式（Branching）
```
任务：根据天气决定活动

[查询天气]
     ↓
[条件判断]
   ↙    ↘
  晴      雨
  ↓      ↓
[户外]   [室内]
```

**适用**：需要根据条件选择不同路径

---

### 模式 3：循环模式（Loop）
```
任务：处理文件夹中的所有文件

[获取文件列表]
     ↓
[循环开始]
  [读取文件] → [LLM 处理] → [保存结果]
[还有下一个？] → 是 → 继续循环
               → 否 → [结束]
```

**适用**：批量处理多个项目

---

### 模式 4：并行模式（Parallel）
```
任务：同时查询多个数据源

[开始]
  ↓
┌─────┬─────┬─────┐
↓     ↓     ↓     ↓
[天气] [新闻] [股票] [邮件]
└─────┴─────┴─────┘
  ↓
[汇总所有结果]
```

**适用**：互不依赖的多个任务，节省时间

---

### 模式 5：错误处理模式（Error Handling）
```
任务：可靠的网络请求

[发送请求]
     ↓
[成功？]
   ↙    ↘
  是     否
  ↓      ↓
[继续] [重试3次？]
         ↙      ↘
        是        否
        ↓         ↓
     [重试]    [报错]
```

**适用**：关键任务，需要容错

## 🚀 性能优化技巧

### 1️⃣ 模型选择
**根据任务选模型**：

| 任务类型 | 推荐模型 | 原因 |
|----------|----------|------|
| 简单对话 | Qwen 2.5 0.5B | 速度快，省电 |
| 复杂推理 | Qwen 2.5 3B | 能力强 |
| 代码生成 | Llama 3.2 3B | 代码优化 |
| 英文任务 | Llama 3.2 3B | 英文更准 |

### 2️⃣ 上下文管理
**问题**：对话太长会：
- 变慢（处理更多 tokens）
- 变傻（丢失早期信息）
- 内存不足（崩溃）

**解决方案**：
```
✅ 定期清除对话（每 20 轮）
✅ 使用工作流代替长对话
✅ 开启"自动摘要"（保留关键信息）
✅ 导出重要对话后清除
```

### 3️⃣ 内存优化
**节省内存的设置**：
- ✅ 开启 KV Cache 量化（q4_0）
- ✅ 限制上下文窗口（2048 而非 4096）
- ✅ 关闭不用的后台应用
- ✅ 避免同时运行多个大模型

### 4️⃣ 速度优化
**提升推理速度**：
- ✅ 使用更小模型（0.5B vs 3B）
- ✅ 降低生成长度（max_tokens = 512）
- ✅ 关闭不必要的工具（减少 schema tokens）
- ✅ 避免低电量模式

**速度参考**（iPhone 15 Pro）：
| 模型 | 速度 | 内存 |
|------|------|------|
| Qwen 0.5B | 35-45 tok/s | 0.8GB |
| Qwen 3B | 18-25 tok/s | 2.0GB |
| Llama 3B | 15-22 tok/s | 2.2GB |

## 🔧 高级工具技巧

### 1️⃣ 工具链式调用
```
你："查询今天日程，如果有会议，
  提前 30 分钟提醒我，
  并在会议结束后询问我的反馈"

LocalMind 自动链式调用：
1. [ios.calendar.query] → 获取日程
2. [条件判断] → 有会议？
3. [ios.reminders.create] → 创建提醒
4. [ios.calendar.onEventEnd] → 监听会议结束
5. [发送通知] → 询问反馈
```

### 2️⃣ 混合执行策略
```
你："总结这篇论文（PDF），并翻译成日文"

LocalMind 智能选择：
1. [ios.files.read] → 本地读取 PDF（隐私）
2. [云端 GPT-4] → 总结内容（非敏感）
3. [本地 LLM] → 翻译成日文（隐私）
```

**设置混合策略**：
设置 → 高级选项 → 执行模式 → 智能路由

## 💡 故障排查清单

### AI 回复不准确
```
检查清单：
□ Temperature 是否过高？（建议 0.3-0.7）
□ 提示词是否明确？（参考"提示词优化"）
□ 模型是否合适？（复杂任务用 3B+）
□ 上下文是否太长？（尝试清除对话）
```

### 工作流不运行
```
检查清单：
□ 是否开启后台执行权限？
□ 触发器时间是否正确？
□ 工具权限是否授权？
□ 查看运行历史（错误信息）
□ 测试运行，观察哪步失败
```

### 应用崩溃
```
检查清单：
□ 设备内存是否足够？（清理后台）
□ 模型是否过大？（小设备用 0.5B-1B）
□ iOS 版本是否支持？（需 17.0+）
□ 重装应用（保留模型文件）
```
