## 🎯 基本问题

### Q1：LocalMind 是什么？
**A**：LocalMind Agent OS 是一个运行在 iPhone/iPad 上的本地 AI Agent 系统。它不仅能聊天，还能执行任务、编排工作流、调用 iOS 系统功能（如健康、日历、HomeKit 等）。所有 AI 推理都在你的设备上完成，数据永不离开你的设备。

### Q2：需要网络吗？
**A**：
- **基础功能**：不需要网络，下载模型后可完全离线使用
- **可选功能**：如需连接云端 API（OpenAI/Anthropic 等）或查询实时信息，需要网络
- **推荐设置**：开启"完全离线模式"，获得最佳隐私保护

### Q3：支持哪些设备？
**A**：

| 设备类型 | 最低要求 | 推荐配置 |
|---------|---------|---------|
| iPhone | iPhone 12（6GB RAM） | iPhone 15 Pro（8GB RAM） |
| iPad | iPad Pro 2018+ | iPad Pro M 系列 |
| Mac | Apple Silicon（M1+） | M2/M3 Pro 及以上 |
| 系统版本 | iOS 17.0+ | iOS 17.0+ |

### Q4：支持中文吗？
**A**：✅ 完全支持中文！
- 界面：简体中文、繁体中文、英文
- AI 对话：支持中文输入输出
- 模型推荐：Qwen 2.5 系列对中文优化最好

## 💬 聊天功能

### Q5：为什么 AI 回复很慢？
**A**：检查以下原因：

```
检查清单：
□ 设备是否太老？（iPhone 12 建议用 0.5B 模型）
□ 模型是否过大？（3B 模型需要 8GB RAM）
□ 是否开启低电量模式？（会限制性能）
□ 后台是否有很多应用？（双击 Home 键清理）
□ 模型是否正在加载？（首次对话会慢一些）
```

**速度参考**（iPhone 15 Pro）：
- Qwen 0.5B：35-45 tokens/秒
- Qwen 3B：18-25 tokens/秒
- Llama 3B：15-22 tokens/秒

### Q6：AI 开始说胡话/乱码怎么办？
**A**：

**立即操作**：
1. 点击 **停止** 按钮中断生成
2. 清除当前对话（上下文太长会混乱）
3. 降低 Temperature 到 0.3-0.5

**长期解决**：
- 使用更高质量的模型（Qwen 2.5 3B 或 Llama 3.2 3B）
- 避免上下文超过 20 轮对话
- 提示词更明确具体

### Q7：如何复制 AI 的回复？
**A**：
1. **长按** AI 回复气泡
2. 选择 **复制文本**（整条）或 **选择文本**（部分）
3. 粘贴到其他应用

### Q8：聊天记录会丢失吗？
**A**：
- **基础版**：聊天记录保存在本地，卸载应用会丢失
- **Pro 版**：支持 iCloud 同步，跨设备同步
- **备份建议**：定期导出重要对话（分享 → 导出为 Markdown）

### Q9：可以删除某条消息吗？
**A**：可以。
1. 长按要删除的消息
2. 选择 **删除**
3. 确认删除

**注意**：删除后无法恢复，建议先导出。

## 📊 工作流问题

### Q10：什么是工作流？和普通聊天有什么区别？
**A**：

**普通聊天**：
```
你："帮我总结这封邮件"
AI："好的，总结是..."
（一次性的，不会自动重复）
```

**工作流**：
```
你："每周一早上 9 点总结上周邮件"
AI："✅ 已创建工作流，将自动执行"
（持久化，每周自动运行）
```

工作流是自动化的任务编排，可以：
- ⏰ 定时触发（每天、每周、特定时间）
- 🔄 多步骤执行（查询 → 分析 → 通知）
- 🧠 条件判断（如果... 就...）
- 🔁 循环处理（对每封邮件...）

### Q11：如何创建工作流？
**A**：推荐用自然语言创建（最简单）：

1. 打开 **☰ 菜单** → **工作流**
2. 点击 **+** 号
3. 用自然语言描述需求：
   ```
   "每天早上 8 点告诉我今天的日程"
   "每周五下午总结本周任务"
   "如果我到家时天黑了，开灯并播放音乐"
   ```
4. AI 自动生成可视化流程
5. 确认并保存

### Q12：工作流不运行怎么办？
**A**：排查步骤：

```
检查清单：
□ 是否开启后台执行权限？
  → 设置 → 通用 → 后台 App 刷新 → 开启 LocalMind

□ 触发器时间是否正确？
  → 编辑工作流 → 检查时间设置

□ iOS 是否杀死了后台？
  → 双击 Home 键，确认 LocalMind 还在运行

□ 查看运行历史：
  → 长按工作流 → 查看运行历史 → 查看错误日志
```

### Q13：可以修改已创建的工作流吗？
**A**：可以。
1. 工作流列表 → 长按工作流
2. 选择 **编辑**
3. 进入可视化编辑器，拖拽修改步骤
4. 保存修改

### Q14：工作流支持哪些触发器？
**A**：

| 触发器类型 | 说明 | 示例 |
|-----------|------|------|
| 定时触发 | 按 cron 表达式 | 每天 9:00、每周一 |
| 事件触发 | 系统事件 | 位置变化、收到邮件 |
| 手动触发 | 用户点击 | 点击运行按钮 |

**Cron 表达式简单模式**：
```
每天 [时间]       → 0 8 * * *
每周 [星期] [时间] → 0 9 * * 1（周一）
每月 [日期] [时间] → 0 10 1 * *（每月1号）
```

## 🔧 工具集成

### Q15：有哪些内置工具可以用？
**A**：15+ 内置工具，包括：

**🏥 健康工具**（需授权）：
- 查询步数、心率、睡眠、体重等
- 分析健康趋势
- 生成健康建议

**📅 日历与提醒**（需授权）：
- 查询日程安排
- 创建事件和提醒
- 管理待办事项

**🏠 HomeKit**（需授权）：
- 控制灯光、开关、空调
- 执行场景（晚安、回家等）
- 查询设备状态

**📁 文件管理**：
- 读取 PDF、TXT、Markdown、代码文件
- 写入和编辑文件
- 搜索文件内容

**📸 照片与媒体**（需授权）：
- 搜索照片（按日期、地点）
- OCR 文字识别
- 添加到相册

**📱 其他系统工具**：
- 设备信息（电量、存储、内存）
- 剪贴板读写
- 位置服务（需授权）
- 语音识别和朗读

### Q16：如何授权工具权限？
**A**：
1. 首次使用工具时，会自动弹出授权提示
2. 或手动设置：iOS 设置 → LocalMind → 开启对应权限
3. 可随时在 iOS 设置中关闭权限

### Q17：工具调用失败怎么办？
**A**：

```
排查步骤：
1. 检查权限：
   → iOS 设置 → LocalMind → 确认对应权限已开启

2. 查看工具日志：
   → 设置 → 高级选项 → 工具调用日志

3. 测试工具：
   → 设置 → 工具管理 → 选择工具 → 测试

4. 重新授权：
   → iOS 设置 → LocalMind → 关闭权限 → 重新开启
```

### Q18：可以连接自己的 API（如 OpenAI）吗？
**A**：可以（Pro 版功能）。
1. 设置 → 高级选项 → API 密钥管理
2. 选择 API 类型（OpenAI/Anthropic/Gemini）
3. 输入你的 API Key（存储在 iOS Keychain 加密）
4. 在混合执行模式中可选择使用云端 API

### Q19：支持 MCP 服务器吗？
**A**：支持（Pro+ 版功能）。
1. 设置 → 高级选项 → MCP 服务器
2. 点击 **+** 添加服务器 URL
3. 支持 HTTP MCP 服务器（如 Home Assistant）
4. 不支持 stdio（iOS 限制）

## ⚡ 性能与速度

### Q20：如何让 AI 回复更快？
**A**：

**立即可做的**：
- ✅ 使用更小模型（Qwen 0.5B > 3B）
- ✅ 清理后台应用
- ✅ 关闭低电量模式
- ✅ 缩短生成长度（设置 → max_tokens = 512）

**长期优化**：
- ✅ 开启 KV Cache 量化（设置 → q4_0）
- ✅ 限制上下文窗口（2048 vs 4096）
- ✅ 避免同时运行多个大模型

**速度对比**：

| 模型 | iPhone 12 | iPhone 15 | iPhone 15 Pro |
|------|----------|----------|----------------|
| Qwen 0.5B | 12 tok/s | 25 tok/s | 40 tok/s |
| Qwen 3B | 5 tok/s | 12 tok/s | 22 tok/s |

### Q21：应用占用多少存储空间？
**A**：

| 组件 | 大小 |
|------|------|
| 应用本身 | 45MB |
| Qwen 0.5B 模型 | 350MB |
| Qwen 3B 模型 | 1.8GB |
| Llama 3B 模型 | 2.1GB |
| 聊天记录（100 轮） | ~2MB |

**建议**：
- 小设备只用 1 个模型（0.5B）
- 定期清理不用的模型
- 导出后清除旧聊天记录

### Q22：会很耗电吗？
**A**：
- **待机**：几乎不耗电（与正常 App 相同）
- **AI 推理中**：会增加 20-40% 耗电（GPU 工作）
- **工作流后台运行**：耗电很低（原生工具调用）

**省电建议**：
- ✅ 使用小模型（0.5B 比 3B 省电 60%）
- ✅ 避免过长对话（生成 1000 tokens > 生成 100 tokens）
- ✅ 不用的话完全关闭应用

## 🔒 隐私与安全

### Q23：我的数据会发送到云端吗？
**A**：**默认不会**。

**LocalMind 的隐私承诺**：
- ✅ 所有 AI 推理在你的设备上完成
- ✅ 不需要注册账号
- ✅ 不需要上传任何数据
- ✅ 即使连接云端 API，也只发送非敏感信息
- ✅ 你可以开启"完全离线模式"（禁用所有网络）

**透明化**：
- 设置 → 隐私 → 数据流向可视化
- 每个工具都标注：🔒 本地 / 🌐 可选云端

### Q24：健康数据是否安全？
**A**：**完全安全**。

- HealthKit 数据只在你的设备上读取
- AI 分析在本地完成
- 除非你明确配置，否则不会发送给任何第三方
- 健康数据不保存在聊天记录中（除非你要求）

### Q25：API Key 如何存储？
**A**：
- 所有 API Key 存储在 **iOS Keychain** 中
- Keychain 是 iOS 的系统级加密存储
- 即使设备越狱也很难提取
- 可随时在设置中删除

### Q26：可以完全离线使用吗？
**A**：**可以**。

1. 设置 → 隐私 → 开启"完全离线模式"
2. 或使用飞行模式
3. 所有功能（聊天、工作流、工具）都可离线使用
4. 唯一限制：无法调用云端 API 或查询实时信息

## 🔧 故障排查

### Q31：应用崩溃怎么办？
**A**：

```
排查步骤：
1. 检查设备内存：
   → 设置 → 通用 → iPhone 存储空间
   → 确保至少有 2GB 可用空间

2. 模型是否过大？
   → iPhone 12/13：只用 0.5B-1B 模型
   → iPhone 14+：可用 3B 模型

3. 清理后台应用：
   → 双击 Home 键 → 滑掉所有应用

4. 重装应用（保留模型）：
   → 长按应用图标 → 删除应用
   → 重新从 App Store 安装
   → 模型文件通常不会丢失
```

### Q32：模型下载失败怎么办？
**A**：

**原因 1：网络不稳定**
- 使用 Wi-Fi 而非蜂窝网络
- 暂停其他大流量下载
- 尝试分段下载（小模型优先）

**原因 2：存储空间不足**
- 检查：设置 → 通用 → iPhone 存储空间
- 删除不用的应用或照片
- 至少保留 2GB 可用空间

**原因 3：Hugging Face 限制**
- 某些模型需要 Hugging Face 账号
- 登录 huggingface.co 注册免费账号
- 在 LocalMind 设置中输入 Hugging Face Token

### Q33：工作流执行出错怎么办？
**A**：

**查看错误日志**：
1. 工作流列表 → 长按工作流
2. 选择 **查看运行历史**
3. 查看失败的执行记录
4. 点击错误信息查看详情

**常见错误**：

| 错误信息 | 原因 | 解决方案 |
|-----------|------|----------|
| "权限被拒绝" | 未授权工具权限 | iOS 设置中开启权限 |
| "内存不足" | 模型过大 | 使用更小模型 |
| "网络错误" | 需要网络 | 连接 Wi-Fi 或关闭离线模式 |
| "工具超时" | 执行时间过长 | 拆分复杂任务 |

### Q34：AI 回复质量差怎么办？
**A**：

**优化提示词**：
```
❌ 不好："写点东西"
✅ 更好："用 300 字介绍人工智能，适合初学者"

❌ 不好："帮我分析"
✅ 更好："分析以下销售数据，找出：1.最高月份 2.同比增长 3.改进建议"
```

**调整参数**：
- Temperature：0.3-0.7（更准确）
- 使用更高质量模型（Qwen 2.5 3B > 0.5B）
- 清除长对话（上下文太长会混乱）
