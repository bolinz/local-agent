## 🔒 本地数据处理详解

### 1. AI 推理（核心功能）

**处理方式**：
- ✅ 所有 AI 推理在你的设备上完成
- ✅ 使用 Apple MLX 框架，Metal GPU 加速
- ✅ 模型权重存储在本地，不会上传
- ✅ 聊天记录仅存储在本地 SQLite 数据库

**数据流向**：
```
你输入消息
    ↓
本地 LLM 推理（设备内）
    ↓
生成回复
    ↓
显示在你的设备上
```

**是否离开设备**：❌ **绝不会**

---

### 2. 健康数据分析

**处理方式**：
- ✅ 通过 iOS HealthKit 框架读取数据
- ✅ 数据仅在你的设备上查询和分析
- ✅ AI 分析在本地完成
- ✅ 健康数据不会发送到云端

**数据流向**：
```
HealthKit 查询
    ↓
本地 LLM 分析（设备内）
    ↓
生成健康建议
    ↓
显示在你的设备上
```

**是否离开设备**：❌ **绝不会**

**授权控制**：
- 可以在 iOS 设置 → 隐私 → 健康中关闭
- 关闭后无法使用健康功能

---

### 3. 日历和提醒管理

**处理方式**：
- ✅ 通过 iOS EventKit 框架访问
- ✅ 所有查询和修改在本地完成
- ✅ 数据不会发送到我们的服务器（因为我们没有服务器）

**数据流向**：
```
EventKit 查询
    ↓
本地处理（设备内）
    ↓
创建/修改事件
    ↓
保存到 iOS 日历/提醒
```

**是否离开设备**：❌ **绝不会**

---

### 4. 文件操作

**处理方式**：
- ✅ 通过 iOS FileManager 访问
- ✅ 仅访问你明确授权的文件
- ✅ 读取、写入、搜索都在本地完成

**数据流向**：
```
你选择文件
    ↓
本地读取（设备内）
    ↓
本地 LLM 处理（可选）
    ↓
保存到本地文件系统
```

**是否离开设备**：❌ **绝不会**

---

### 5. HomeKit 智能家居

**处理方式**：
- ✅ 通过 iOS HomeKit 框架控制
- ✅ 设备状态查询和控制都在本地
- ✅ 不会发送到我们的服务器

**数据流向**：
```
HomeKit 查询状态
    ↓
本地处理（设备内）
    ↓
发送控制指令
    ↓
设备执行动作
```

**是否离开设备**：❌ **绝不会**

## 🌐 云端 API 使用说明（可选）

### 何时会连接云端？

**默认情况**：本应用完全离线，**不会连接任何服务器**。

**仅在你主动配置后才会连接云端**：
1. 你在设置中添加了云端 API Key
2. 你创建了使用云端 API 的工作流
3. 你明确选择"使用云端模型总结/翻译"

### 云端数据传输详情

**传输内容**：

| 传输内容 | 是否加密 | 接收方 | 用途 | 是否包含敏感数据 |
|---------|---------|-------|------|----------------|
| 你输入的文本 | ✅ HTTPS | 你选择的 API | 生成回复 | ⚠️ 取决于你输入什么 |
| API Key | ✅ HTTPS | 你选择的 API | 身份验证 | ❌ 不包含 |
| 健康数据 | ❌ 不会传输 | - | - | - |
| 日历数据 | ❌ 不会传输 | - | - | - |
| 文件内容 | ❌ 不会传输 | - | - | - |

**重要保证**：
- ✅ 敏感数据（健康、日历、本地文件）**绝不会**发送到云端
- ✅ 你可以精确控制每条消息使用本地还是云端
- ✅ 你可以随时删除 API Key，回到完全离线模式

### 第三方数据处理

如果你使用云端 API，数据将由以下第三方处理：

| 提供商 | 数据处理政策 | 隐私政策链接 |
|---------|---------------|------------------|
| **OpenAI** | 根据你与其的协议 | https://openai.com/policies/privacy-policy |
| **Anthropic** | 根据你与其的协议 | https://www.anthropic.com/privacy |
| **Google Gemini** | 根据你与其的协议 | https://policies.google.com/privacy |

**我们不对第三方的数据处理负责。**

## 🎛️ 你的控制权

### 数据管理选项

| 操作 | 方法 | 效果 |
|------|------|------|
| **查看所有数据** | 直接在应用内查看 | 聊天记录、工作流配置 |
| **导出数据** | 分享 → 导出为 Markdown/PDF/JSON | 本地保存副本 |
| **删除聊天记录** | 设置 → 聊天管理 → 清除 | 彻底删除，无法恢复 |
| **删除模型** | 设置 → 模型管理 → 删除 | 释放存储空间 |
| **删除 API Key** | 设置 → 高级选项 → API 密钥管理 | 停止使用云端 API |
| **撤销权限** | iOS 设置 → LocalMind → 关闭开关 | 停止访问对应数据 |
| **完全删除所有数据** | 长按应用图标 → 删除应用 | 所有数据将被清除 |

### 隐私设置

**完全离线模式**（推荐）：
1. 设置 → 隐私 → 开启"完全离线模式"
2. 效果：禁用所有网络请求
3. 即使你配置了 API Key，也不会使用

**选择性使用云端**：
1. 设置 → 高级选项 → 执行模式 → 智能路由
2. 效果：敏感任务用本地，非敏感任务可用云端
3. 你可以为每个工作流单独设置

## 🔐 数据分享说明

### 我们不会分享你的数据

**明确承诺**：
- ❌ 我们不会出售你的数据
- ❌ 我们不会出租你的数据
- ❌ 我们不会与第三方分享你的数据（除非你主动使用其 API）
- ❌ 我们不会将你的数据用于广告投放
- ❌ 我们不会将你的数据用于用户画像

### 例外情况（法律要求）

**仅在以下情况，我们可能被迫披露数据**：
1. 收到有效的法院命令或传票
2. 执法机构依法要求
3. 保护我们的合法权利

**但是**：由于所有数据都存储在你设备上，我们实际上**无法提供**你的数据。执法机构需要直接从你的设备获取。

## 🔒 数据安全技术

### 本地存储安全

| 数据类型 | 存储方式 | 加密方式 | 其他应用能否访问 |
|---------|---------|---------|----------------|
| 聊天记录 | SQLite 数据库 | iOS 沙盒保护 | ❌ 不能 |
| API Key | iOS Keychain | 硬件级加密（Secure Enclave） | ❌ 不能 |
| 模型文件 | 文件系统 | iOS 沙盒保护 | ❌ 不能 |
| 工作流配置 | JSON 文件 | iOS 沙盒保护 | ❌ 不能 |

### 网络传输安全（如启用云端 API）

- ✅ **TLS 1.3 加密**：所有网络请求使用最新加密标准
- ✅ **证书锁定**：防止中间人攻击
- ✅ **无第三方 SDK**：不加载任何分析或广告 SDK
- ✅ **最小权限原则**：仅传输完成任务必需的数据

## 👶 儿童数据处理

**我们不收集 13 岁以下儿童的数据**（或你所在司法管辖区的法定年龄）。

由于我们不收集任何数据，因此不存在儿童数据泄露风险。所有处理都在儿童自己的设备上完成。

## 📋 快速问答（Q&A）

### Q1：LocalMind 会收集我的聊天记录吗？
**A**：❌ 不会。所有聊天记录仅存储在你自己的设备上。

### Q2：我的健康数据会泄露吗？
**A**：❌ 不会。健康数据通过 iOS HealthKit 读取，仅在你的设备上使用，绝不离开设备。

### Q3：使用云端 API 安全吗？
**A**：✅ 安全。我们使用 HTTPS 加密传输，且仅传输你输入的非敏感内容。敏感数据（健康、日历等）绝不会发送。

### Q4：可以完全离线使用吗？
**A**：✅ 可以。开启"完全离线模式"，或直接使用飞行模式。

### Q5：我的数据会被用于训练 AI 模型吗？
**A**：❌ 不会。我们不收集数据，因此无法用于训练。即使你使用云端 API，根据 OpenAI/Anthropic 的政策，你的数据也不会用于训练（除非你主动选择加入）。
