# LocalMind Agent OS - 隐私政策

**生效日期**：2026 年 5 月 1 日  
**最后更新**：2026 年 5 月 3 日

---

## 📋 概述

LocalMind Agent OS（以下简称"本应用"或"我们"）深知隐私的重要性。本隐私政策说明了我们如何收集、使用和保护你的信息。

**核心理念**：**我们不收集你的任何个人数据。**

---

## 🔒 数据收集

### 我们收集的数据

**简单回答：我们不收集任何数据。**

| 数据类型 | 是否收集 | 说明 |
|---------|---------|------|
| 个人身份信息 | ❌ 否 | 无需注册账号 |
| 聊天记录 | ❌ 否 | 仅存储在你的设备上 |
| 健康数据 | ❌ 否 | 仅在你的设备本地读取 |
| 日程信息 | ❌ 否 | 仅在你的设备本地访问 |
| 文件内容 | ❌ 否 | 仅在你的设备本地处理 |
| 设备信息 | ❌ 否 | 仅在你的设备本地使用 |
| 位置数据 | ❌ 否 | 仅在你的设备本地查询（如授权） |
| 使用统计 | ❌ 否 | 无分析 SDK，无追踪 |
| 崩溃日志 | ⚠️ 可选 | 仅在你主动提交反馈时发送 |

### 我们存储的数据

**所有数据都存储在你自己的设备上**：

| 数据类型 | 存储位置 | 是否可以删除 |
|---------|---------|--------------|
| 聊天记录 | 本地 SQLite 数据库 | ✅ 可以（一键清除） |
| 模型文件 | 本地文件系统 | ✅ 可以（删除模型） |
| API 密钥 | iOS Keychain（加密） | ✅ 可以（设置中删除） |
| 工作流配置 | 本地文件系统 | ✅ 可以（删除工作流） |
| 用户设置 | 本地 UserDefaults | ✅ 可以（重装应用） |

## 🔐 云端 API 使用（可选）

### 何时会连接云端？

**默认情况**：本应用完全离线运行，不会连接任何服务器。

**仅在以下情况会连接网络**（需要你主动配置）：
1. 你在设置中添加了云端 API Key（OpenAI/Anthropic/Gemini 等）
2. 你创建了使用云端 API 的工作流
3. 你主动查询实时信息（如天气、新闻）

### 云端数据传输

**我们不会传输你的数据到云端**。当使用云端 API 时：

| 传输内容 | 是否加密 | 谁接收 | 用途 |
|---------|---------|---------|------|
| 你输入的消息 | ✅ HTTPS | 你选择的 API 提供商 | 生成 AI 回复 |
| API Key | ✅ HTTPS | 你选择的 API 提供商 | 身份验证 |

**重要说明**：
- ✅ 敏感数据（健康、日历、本地文件）**不会**发送到云端
- ✅ 你可以选择哪些内容使用云端 API
- ✅ 你可以随时删除 API Key，回到完全离线模式

### 第三方 API 提供商

如果你使用云端 API，还需遵守对应提供商的政策：
- **OpenAI**：https://openai.com/policies/privacy-policy
- **Anthropic**：https://www.anthropic.com/privacy
- **Google Gemini**：https://policies.google.com/privacy

## 🔒 数据安全

### 本地存储安全

- ✅ **SQLite 数据库**：存储在应用沙盒内，其他应用无法访问
- ✅ **API Key**：存储在 iOS Keychain 中，硬件级加密
- ✅ **文件访问**：遵循 iOS 沙盒机制，仅访问你授权的文件
- ✅ **模型文件**：存储在应用目录，无法被其他应用读取

### 传输安全（如启用云端 API）

- ✅ **HTTPS 加密**：所有网络请求使用 TLS 1.3 加密
- ✅ **证书锁定**：防止中间人攻击
- ✅ **无追踪器**：不加载任何第三方分析或广告 SDK

## 👤 你的权利（GDPR/CCPA）

根据 GDPR（欧盟）和 CCPA（加州）等隐私法规，你享有以下权利：

### 访问权
**说明**：你有权知道我们收集了哪些数据。  
**我们的回应**：我们不收集任何数据，因此无数据可提供。

### 更正权
**说明**：你有权更正不准确的数据。  
**我们的回应**：所有数据都在你设备上，你可以直接修改或删除。

### 删除权（被遗忘权）
**说明**：你有权删除你的个人数据。  
**操作方法**：
1. 打开本应用 → 设置 → 聊天管理 → 清除所有对话
2. 或：长按应用图标 → 删除应用（所有数据将被清除）

### 数据携带权
**说明**：你有权以结构化格式导出数据。  
**操作方法**：
1. 聊天记录：分享 → 导出为 Markdown/PDF
2. 工作流：长按 → 导出为 JSON/YAML

### 反对权和限制处理权
**说明**：你有权限制或反对数据处理。  
**操作方法**：
1. 开启"完全离线模式"（设置 → 隐私）
2. 撤销任何已授权的权限（iOS 设置）
3. 删除所有 API Key（设置 → 高级选项）
