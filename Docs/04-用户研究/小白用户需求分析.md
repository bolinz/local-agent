# 小白用户需求分析

> 调研对象：手机和AI小白用户  
> 调研日期：2026年5月3日  
> 调研方式：文档阅读 + 场景想象

---

## 一、产品吸引力评估

### ✅ 吸引小白的地方

1. **隐私保护** - "数据不离开手机"这点很打动我，现在APP都偷数据，这个说完全本地，感觉安全
2. **一次性68元** - 比那些每月扣费的APP良心，不用担心忘记取消订阅
3. **能帮我做事** - 不只是聊天，还能提醒我开会、控制家里灯、看健康数据，听起来很智能

### ❌ 让小白犹豫的地方

1. **太复杂了** - "MLX框架"、"tokens/秒"、"4-bit量化"这些都是啥？我一个小白哪懂这些
2. **要下载模型** - 还要选Qwen还是Llama？多大合适？我只是想用个AI助手，怎么这么麻烦
3. **要设权限** - 健康、日历、HomeKit...每个都要我决定开不开，我哪知道该开哪个
4. **工作流是啥** - 文档里说"可视化工作流编辑器"，我看了还是不懂这是干啥的，对我有啥用

## 二、小白用户的核心需求

### 1. 简化设置流程

- **能不能别让我选模型？** 直接帮我选好，我的手机是iPhone 13，你告诉我下哪个就行，别让我纠结
- **能不能一键设置？** 比如"帮我设置好管理日程和健康数据"，自动把需要的权限和模型都配好，别让我自己琢磨
- **别让我看技术规格** - 我不在乎什么iOS 17.0、6GB内存，我只想知道"我的手机能不能用"

### 2. 说人话的界面

- **"tokens/秒"** → "AI回复速度"
- **"工作流"** → "自动任务"
- **"Agent"** → "智能助手"
- 所有技术术语都换成小白能懂的日常用语

### 3. 视频教程

- 文字看不懂，能不能拍个30秒视频，演示一下怎么用语音让AI帮我设提醒？
- 每一步都要有视频，别光给文字说明

### 4. 场景化引导

别一上来就让我聊天，先问我"你想用它干啥？"，然后针对性教我：
- 想管日程 → 教我设提醒、看日历
- 想看健康 → 教我查心率、睡眠
- 想控制家电 → 教我连HomeKit

### 5. 小白专用客服

- 遇到问题别说"查看常见问题.md"
- 我要能直接问"为什么AI不理我了"，然后得到人话回答
- 最好有语音问答："小Local，我该怎么办？"

## 三、小白用户想要的使用场景（不局限于现有功能）

### 💰 省钱管家

- 拍小票自动记账，月底告诉我"这个月奶茶花了800块，少喝点"
- 比价："这个洗发水京东卖多少，拼多多呢？"
- 提醒我："信用卡还款日还有3天"

### 👶 带娃神器

- 拍作业题，用**小学生能懂的话**讲给我听，我再教孩子
- "孩子发烧38.5度怎么办"，给我应急处理步骤
- 编睡前故事："要一个关于小恐龙的，5分钟能讲完"

### 💬 社交外挂

- "怎么回复老板的批评，既要认错又不要显得太怂"
- "给暗恋的人发第一条微信，别太主动也别太冷淡"
- "我妈说'你看看别人家孩子'，我该怎么回"

### 🍳 厨房小白救星

- "我冰箱里有鸡蛋、西红柿、面条，能做什么"
- 拍食材照片，告诉我**保质期还有多久**
- "这个调料放多少，我手抖倒多了怎么办"

### 😴 睡眠改善师

- 分析我的睡眠数据："为什么我总在凌晨3点醒"
- "今晚失眠了，陪我聊聊，别让我刷手机"
- 白噪音+冥想引导，协助我入睡

### 👴 给爸妈用的模式

- **大字版界面**，我爸老花眼看得清
- **语音操作**："小Local，明天天气咋样"
- **一键求助**：摔倒了喊"救命"，自动给子女发位置+录音
- **吃药提醒**：比手机自带的强，能识别药盒照片

### 🆘 应急小助手

- 迷路了："我在哪，怎么去最近地铁站，用语音导航"
- 受伤了："手割破了先做什么后做什么"，一步步语音指导
- 遇到骗子："这个短信说中奖了，是不是骗局"

### 📝 打工人摸鱼

- "帮我写个请假理由，要真实，老板看不出来"
- "同事甩锅给我，我该怎么在群里回复，既要澄清又要给面子"
- "周报怎么写，我这周其实没干啥"

### 💔 情感树洞

- "我暗恋三年了不敢表白，我是不是很怂"（存本地，绝不外传）
- "今天被分手了，陪我聊会儿"
- "怎么知道自己是不是抑郁了"

### 🎮 娱乐陪玩

- "推荐5部类似《流浪地球》的电影"
- "给我写个搞笑的朋友圈文案，今天去爬山了"
- "给我家猫起个名字，要霸气点的"

## 四、小白用户最想要的功能

### 1. 一键求助按钮
遇到任何问题，按住说话，它帮我搞定

### 2. 场景模式切换
- "工作模式" - 专注办公、屏蔽干扰
- "带娃模式" - 作业辅导、育儿建议
- "老人模式" - 大字、语音、简化操作

### 3. 拍照即服务
拍啥都能识别：
- 📷 小票 → 自动记账
- 💊 药盒 → 吃药提醒
- 📝 作业题 → 讲解思路
- 🛒 商品条码 → 比价

### 4. 真的不上传
给我看个"已断开网络"的图标，我才放心
- 状态栏显示 🔒 本地模式
- 每次联网都要明确问我："要联网查天气吗？"

---

## 五、总结

### 小白用户要的不是"AI聊天"
而是**"24小时在线的万能小弟"**，能帮我搞定生活里各种琐事，而且**嘴严**（不泄露隐私）。

### 产品改进建议

1. **零配置启动** - 下载APP → 自动检测手机型号 → 自动下载合适模型 → 直接用
2. **场景化引导** - 首屏问"你想用它做什么"，然后针对性教学
3. **术语翻译** - 把所有技术词换成小白能懂的话
4. **视频优先** - 每个功能都有30秒短视频演示
5. **语音优先** - 小白不爱打字，要能全程语音操作

### 一句话定义

> **LocalMind = 住在我手机里的万能小弟，嘴严、听话、不偷懒、不泄露秘密。**
