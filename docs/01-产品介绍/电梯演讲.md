## 🎯 使用场景演示（附带）

**场景 1：智能邮件助手**
```
用户："帮我把今天收到的邮件分类，重要的转发给我老板，
     广告邮件归档，并总结需要回复的邮件"

LocalMind 自动执行：
1. 获取今天邮件（本地，隐私）
2. 本地 LLM 分类（内容不离开设备）
3. 重要邮件：调用 Mail API 转发
4. 广告邮件：本地操作归档
5. 生成摘要并创建提醒

结果：3 秒完成，零隐私泄露
```

**场景 2：健康生活教练**
```
用户："根据我的运动和睡眠数据，帮我制定下周的健身计划"

LocalMind 执行：
1. 读取 HealthKit 数据（本地）
2. 本地 LLM 分析（敏感数据不离开设备）
3. 生成计划后：调用日历 API 创建事件
4. 设置提醒和通知

结果：个性化建议，健康数据绝不外传
```

**场景 3：智能家居编排**
```
用户："如果我下班回家时天黑了，自动开灯并播放音乐"

LocalMind 创建持久化监听：
1. 监听位置变化（iOS 原生）
2. 检查时间（是否天黑）
3. 调用 HomeKit 开灯
4. 调用 Music API 播放音乐

结果：一次设置，永久运行
```
