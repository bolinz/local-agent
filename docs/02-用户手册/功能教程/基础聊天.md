## 💬 聊天界面介绍

### 主界面布局

```
┌─────────────────────────────────┐
│  LocalMind Agent OS    [设置]  │
├─────────────────────────────────┤
│  2026年5月3日 上午10:23        │
│                             │
│  🤖 你好！我是 LocalMind    │
│     你的本地 AI 助手。        │
│                             │
│  👤 请介绍一下你自己       │
│                             │
│  🤖 我是运行在你设备上的  │
│     AI Agent，可以帮你完成  │
│     各种任务...              │
│                             │
│  👤 [正在输入...]          │
│                             │
│ ┌─────────────────────────┐ │
│ │ 输入消息...      [发送] │ │
│ └─────────────────────────┘ │
└─────────────────────────────────┘
```

### 界面元素说明

| 元素 | 位置 | 功能 |
|------|------|------|
| **设置按钮** | 左上角 | 进入设置页面，调整参数 |
| **模型名称** | 顶部居中 | 显示当前使用模型，点击可切换 |
| **聊天记录** | 中间区域 | 显示所有对话，支持长按操作 |
| **推理速度** | 消息下方 | 显示 tokens/秒、耗时 |
| **停止按钮** | 生成中显示 | 中断当前生成 |
| **输入框** | 底部 | 输入消息，支持多行 |
| **发送按钮** | 输入框右侧 | 发送消息 |

## ✍️ 发送消息

### 基本操作
1. 点击底部输入框
2. 输入你的问题或指令
3. 点击 **发送** 或按键盘 **Return**

### 多行输入
- 输入时按 **Return** = 换行
- 点击 **发送** 按钮提交
- 或长按 Return，出现"发送"选项

### 消息操作（长按消息）
```
┌──────────────────┐
│  📋 复制文本      │
│  📤 分享        │
│  🔄 重新生成     │
│  🗑️ 删除        │
│  📝 编辑并重新发送│
└──────────────────┘
```

## 🤖 理解 AI 回复

### 回复格式
LocalMind 支持 **Markdown 渲染**：

**代码示例**：
```swift
let message = "Hello, World!"
print(message)
```

**列表**：
- 项目 1
- 项目 2
  - 子项目

**加粗和强调**：
- **重要信息** 用加粗
- *斜体* 用于次要信息

**表格**：
| 项目 | 值 |
|------|-----|
| A | 100 |
| B | 200 |

### 推理速度显示
每条 AI 回复下方会显示：
```
⚡ 18.5 tokens/秒 | 耗时 2.3秒 | 共 42 tokens
```

**说明**：
- **tokens/秒**：越高越快（iPhone 15 Pro 约 15-30）
- **耗时**：从发送到完成的时间
- **共 N tokens**：生成的内容长度

## 🛑 停止生成

### 何时需要停止
- AI 开始说废话或重复内容
- 你想改变问题方向
- 生成内容已经足够
- 需要紧急中断

### 操作方法
**方法 1**：点击消息下方的 **停止** 按钮
```
🤖 生成中... [停止]
```

**方法 2**：摇晃设备（需开启辅助功能）
**方法 3**：说 "停"/"停止"（语音控制）

### 停止后的处理
- 已生成的内容会保留
- 可以点击 **继续生成**（如果模型支持）
- 或直接发送新消息

## 📋 复制和分享

### 复制文本
1. **长按** AI 回复
2. 选择 **复制文本**
3. 粘贴到其他应用

**部分复制**：
1. 长按回复 → **选择文本**
2. 拖动选择范围
3. 点击 **复制**

### 分享对话
1. 点击右上角 **分享** 按钮
2. 选择分享方式：
   - 📧 邮件
   - 💬 信息
   - 📝 Notes
   - 📄 导出为 PDF
   - 📝 导出为 Markdown

### 导出格式
**Markdown 格式**（推荐）：
```markdown
# LocalMind 对话记录
**时间**：2026年5月3日 10:30

**用户**：请介绍一下你自己

**LocalMind**：我是运行在你设备上的 AI Agent...
```

**PDF 格式**：
- 精美排版
- 包含时间戳
- 适合打印或存档

## 🔄 重新生成回复

如果不满意 AI 的回复：

### 方法 1：重新生成
1. 长按 AI 回复
2. 选择 **重新生成**
3. 等待新回复生成

**注意**：相同输入可能得到不同输出（Temperature > 0）

### 方法 2：编辑并重新发送
1. 长按你的消息
2. 选择 **编辑并重新发送**
3. 修改内容后发送

### 方法 3：调整参数后重试
1. 进入 **设置** → **模型设置**
2. 调整 Temperature（0.1-2.0）
3. 返回聊天，重新发送

**Temperature 建议**：
- **0.1-0.3**：精确任务（翻译、代码）
- **0.7**：平衡（推荐日常使用）
- **1.0-1.5**：创意任务（写作、头脑风暴）

## 🗑️ 管理聊天记录

### 删除单条消息
1. 长按消息
2. 选择 **删除**
3. 确认删除

### 清空整个对话
1. 点击左上角 **设置**
2. 选择 **聊天管理**
3. 点击 **清除当前对话**
4. 确认清除

### 导出后清除
1. 先 **分享** → **导出为 Markdown**
2. 保存到其他位置
3. 再清除对话

## 💡 使用技巧

### 让回复更准确
❌ 不好："介绍一下 AI"  
✅ 更好："用 200 字介绍什么是大语言模型，适合初学者"

❌ 不好："帮我写代码"  
✅ 更好："用 Swift 写一个读取文件的函数，包含错误处理"

### 利用上下文
LocalMind 会记住对话上下文（在当前会话内）：

```
你：北京今天天气怎么样？
AI：北京今天晴，15-28°C

你：那明天呢？  ← AI 知道"明天"指的是北京
AI：明天北京多云转阴，12-25°C
```

### 明确任务类型
- **总结**："用 3 句话总结..."
- **翻译**："将以下内容翻译成英文：[内容]"
- **代码**："用 Python 写一个..."
- **分析**："分析以下数据的趋势：[数据]"

## ⚠️ 常见问题

### Q：AI 回复很慢怎么办？
**A**：检查：
1. 模型是否过大（小设备用 0.5B-1B 模型）
2. 是否开启 **低电量模式**（会限制性能）
3. 后台是否有很多应用（清理后台）

### Q：AI 开始说胡话怎么办？
**A**：
1. 点击 **停止**
2. 清除当前对话（上下文太长会乱）
3. 降低 Temperature 到 0.3-0.5

### Q：如何知道模型在想什么？
**A**：在设置中开启 **显示思考过程**（如果模型支持，如 Qwen3）
