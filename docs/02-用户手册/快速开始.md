# LocalMind Agent OS - 快速开始

## 🎯 5 分钟上手指南

欢迎使用 LocalMind Agent OS！本指南将帮助你在 5 分钟内完成初始设置并发送第一条消息。

---

## 📱 第一步：下载与安装

### 系统要求
- **iOS 17.0+** 或 **iPadOS 17.0+**
- **设备**：iPhone 12 或更新机型（推荐 iPhone 15 Pro 及更新）
- **存储空间**：至少 2GB 可用空间（用于应用和模型）
- **内存**：6GB RAM 最低（8GB 推荐）

### 安装步骤
1. 打开 **App Store**
2. 搜索 "LocalMind Agent OS"
3. 点击 **获取** → **安装**
4. 安装完成后，点击 **打开**

---

## ⚙️ 第二步：初始设置（首次打开）

### 1. 权限授权
应用会请求以下权限（可选，可稍后设置）：
- **通知权限**：接收工作流通知和任务完成提醒
- **健康数据**（可选）：如需使用健康功能
- **日历和提醒**（可选）：如需管理日程
- **HomeKit**（可选）：如需控制智能家居

> 💡 **提示**：你可以随时在 iOS 设置中修改这些权限。

### 2. 选择模型
首次打开会提示选择模型：

| 模型 | 大小 | 适用设备 | 说明 |
|------|------|----------|------|
| **Qwen 2.5 0.5B** | 350MB | 所有设备 | 速度快，适合日常对话 |
| **Qwen 2.5 3B** | 1.8GB | iPhone 13+ | 平衡选择，推荐 |
| **Llama 3.2 3B** | 2.1GB | iPhone 14+ | 英文优化，质量高 |
| **Phi-3 Mini** | 1.3GB | iPhone 12+ | 微软出品，稳定可靠 |

**推荐**：
- 📱 iPhone 12/13：选择 Qwen 2.5 0.5B
- 📱 iPhone 14/15：选择 Qwen 2.5 3B
- 📱 iPad Pro M 系列：可选择更大模型

点击 **下载**，等待下载完成（约 2-5 分钟，取决于网络）。

## 🔧 第四步：基础设置

### 打开设置
点击左上角 **设置图标**（齿轮），进入设置页面。

### 推荐设置项

#### 1. 模型设置
- **Temperature**：0.7（默认，平衡创意和准确性）
- **Top-P**：0.9（默认）
- **最大生成长度**：2048 tokens
- **KV Cache 量化**：q4_0（省内存，速度更快）

#### 2. 界面设置
- **主题**：跟随系统 / 浅色 / 深色
- **强调色**：蓝色（默认）
- **字体大小**：标准 / 大 / 超大

#### 3. 隐私设置
- **完全离线模式**：开启（禁用所有网络请求）
- **API 密钥管理**：如需使用云端 API，在此添加
- **数据清除**：一键清除所有聊天记录和缓存
