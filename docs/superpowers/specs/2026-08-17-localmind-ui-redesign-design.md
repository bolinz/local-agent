# LocalMind 全 App 视觉与信息架构重设计

> 日期：2026-08-17
> 状态：已确认
> 主题：全 App 布局重设计——从"原生 List/Form 骨架"升级为"沉浸式 AI Agent 产品体验"

## 背景

当前 UI 是 POC 骨架：对话页顶部信息堆叠（标题+垃圾桶+状态胶囊）、空状态仅 3 行文字、气泡/列表用原生 Text/List、设置页平铺单条 AgentConfig、无历史会话。用户反馈"布局不够现代，也不像 AI agent"。

## 设计目标

- **全 App 统一视觉语言**（对话/工作流/设置三个 Tab）
- **双模式原生风**：跟随系统浅色/深色，用原生 SwiftUI 但布局、层级、组件更现代
- **Agent 感**：让 AI 的行为可见——思考过程可视化、工具调用卡片化、上下文跟踪展示
- 解决四个痛点：顶部信息堆叠、空状态太无聊、对话组件老套、列表页平庸
- 补历史会话缺口：会话列表 + JSON 持久化

## 方向决策

| 维度 | 决策 |
|---|---|
| 整体方向 | A·沉浸式对话中枢（大标题+状态胶囊一体、空态=能力入口、输入栏带记忆） |
| 风格 | 双模式原生风（系统浅深色自动切换） |
| 历史对话 | 会话列表 + 持久化（StorageService JSON，重启不丢） |
| Agent 配置 | 升级为多 Agent 管理（列表 + 详情两级结构） |
| 视觉质感 | 渐变 orb/图标、发光状态胶囊、渐变发送按钮、精致 Tab 栏 |

## 信息架构

### Tab 1 对话（沉浸式对话中枢）

- **顶部**：大标题 `LocalMind` + 状态胶囊（● 本地运行）合并一行；右上角加"历史会话"入口
- **空状态**：渐变 orb 图标 → 主标语 → 副标语 → 能力 chips（创建提醒/控制家居/总结日程/用药提醒）→ 渐变分隔线 → 输入栏
- **对话流**：
  - 用户消息：渐变底 + 圆角 + 投影，右侧对齐
  - Agent 回复：左侧对齐，浅灰背景
  - **思考过程卡片**：Agent 回复前显示「Agent 思考中」，分步指示器（理解意图 ✓ → 调用工具 ● → 整理回复）
  - **工具调用卡片**：可展开，等宽字体参数 + 绿色成功状态
  - **上下文记忆条**：输入栏上方显示当前会话跟踪的任务摘要（如"正在跟踪 2 个自动任务"）
- **输入栏**：毛玻璃圆角，渐变发送按钮（空文本禁用态灰）

### Tab 2 工作流

- 顶部右上角 **➕ 新建**（补上缺失的"创建工作流"入口）
- **我的自动任务**：渐变图标卡（每张带开关 + 运行统计"每天 8:00 · 已运行 3 次"）
- **模板库**：独立分组，渐变图标卡 + "导入"按钮
- **执行日志**：保留入口

### Tab 3 设置 → Agent 管理

- **Agent 列表**：每个 Agent 一张渐变头像卡（当前态有选中标记），底部虚线"＋新建 Agent"卡
- **Agent 详情**（点击进入）：角色设定（System Prompt 全文）/ 能力（工具开关+权限状态）/ 隐私与推理（数据策略/模型/Temperature）
- **其他设置**：Skills / 模型管理 / 关于·开源

### 历史会话

- 对话页顶部"历史"入口 → 会话列表（首条摘要 / 时间 / 消息数）
- 点击恢复会话；左滑删除
- 存储：`ChatService` 增加会话持久化，按会话 ID 组织，JSON 存 StorageService

## 视觉规范（双模式）

| 元素 | 深色 | 浅色 |
|---|---|---|
| 背景 | #0B0F1A | #FFFFFF |
| 强调渐变 | indigo(6366F1) → violet(8B5CF6) → fuchsia(D946EF) | 同左 |
| 成功状态 | #34D399 | #10B981 |
| 卡片背景 | rgba(148,163,184,0.08) | rgba(148,163,184,0.06) |
| 状态胶囊 | 绿点 + 绿字（#34D399） | 同左 |

- 圆角：卡片 14pt、气泡 20pt、输入栏 26pt
- 阴影：渐变元素带柔和投影
- 字体：SF Pro（系统默认），标题 22pt/800、正文 13pt

## 组件清单（SwiftUI）

- `OrbView`：渐变圆角图标（复用大脑/工具图标）
- `ThinkingCardView`：思考过程分步指示器
- `ToolCallCardView`：工具调用可展开卡片
- `MemoryStripView`：上下文记忆胶囊条
- `GlowPillView`：发光状态胶囊
- `AgentListView` / `AgentDetailView`：多 Agent 管理
- `SessionListView`：历史会话列表
- `GradientIconView`：渐变图标（工作流/模板/Agent 头像通用）

## 数据层变更

- `ChatService`：会话持久化（save/load sessions，按 ID）
- `AgentStore`：从单条 `AgentConfig` 升级为多 Agent 存储（数组）
- 新增模型：`ChatSession`（id/标题/时间/消息）

## 不做的事

- 不引入真实 MLX 推理/云端路由（维持 POC 模拟回复）
- 不改数据模型 `Workflow`/`ChatMessage` 核心结构
- 不做多 Agent 真正的运行时隔离（仅配置层多份，运行时仍走单实例 ChatService）

## 验证方式

1. 单元测试：会话持久化读写、多 Agent 配置存取
2. UI 测试（run-uitests.sh）：三个 Tab 渲染、空状态 chips、思考卡片、会话列表恢复
3. 模拟器截图 + image-reader 校验视觉（无黑边、布局正确）

## 落地顺序

1. 数据层：ChatSession + 会话持久化 + AgentStore 多 Agent
2. 视觉组件：Orb / ThinkingCard / ToolCallCard / MemoryStrip / GlowPill / GradientIcon
3. 对话页重写（空态 + 对话流 + 输入栏 + 历史入口）
4. 工作流页重写（卡片化 + 新建入口）
5. 设置页重写（Agent 管理）
6. 验证与收尾（测试 + 截图校验）
